# Robô Automatizado — demonstração pública / Public demo

> **PT** — Este repositório contém **somente** o gerador de folhas de presença sintéticas e
> exemplos de resultado. **O leitor de marcações não está aqui**: ele é mantido em um
> repositório privado.
>
> **EN** — This repository contains **only** the synthetic attendance-sheet generator and
> sample results. **The mark reader is not included**: it is kept in a private repository.

## Português

### O que é
O Robô Automatizado lê a foto de uma folha de presença e classifica o quadrado da coluna
"P" de cada linha como `P` (marcado com X), `SEM_MARCAÇÃO` (sem marca) ou `REVISAR`
(dúvida: decisão humana). `SEM_MARCAÇÃO` não equivale a falta. A assinatura e o nome nunca
decidem a presença. Todo o processamento é local, e nenhuma imagem é enviada a serviços externos.

### O que há neste repositório
| Parte | Onde | Disponível aqui? |
|---|---|---|
| Gerador de folhas sintéticas | `gerar_folha_sintetica.py` | **Sim**, código autocontido |
| Folhas fictícias e gabarito | `exemplos/` | **Sim** |
| Resultados do leitor sobre essas folhas | `resultados/` | **Sim**, apenas os resultados |
| Leitor de marcações (Fases 1a e 1b) | — | **Não**: repositório privado |

Os arquivos em `resultados/` foram **produzidos pelo leitor original, mantido em repositório
privado**, aplicado às folhas de `exemplos/`. Eles documentam o comportamento do leitor, mas
**não podem ser reproduzidos a partir deste repositório**. Já as folhas e o `gabarito.json` podem
ser regenerados por qualquer pessoa com o script.

### Como gerar as folhas
```bash
pip install numpy opencv-python
python gerar_folha_sintetica.py --saida exemplos
python gerar_folha_sintetica.py --saida exemplos --condicao escura   # só uma condição
```
Condições: `base`, `escura`, `perspectiva_forte`. O script é determinístico e não lê arquivos.
Saída: `folha_sintetica_<condicao>.jpg` e `gabarito.json`, que lista, para cada linha, a marca
desenhada e a classe esperada de um leitor cuidadoso.

### Dados 100% fictícios
Título "LISTA DE PRESENCA - DEMO", curso "Curso Ficticio de Demonstracao", participantes
`PARTICIPANTE FICTICIO NN`, CPF mascarado `000******00` e IDs aleatórios. Não há fotografias
reais, pessoas, logotipos nem identidade de instituições.

### Resultados de exemplo
Em `resultados/relatorio_resultados.md` e `resultados/paineis/`: nas 3 condições, 18 linhas,
P = 5, SEM_MARCAÇÃO = 4, REVISAR = 9, 0 divergências do gabarito e 0 erros graves
(um `P` sem X, ou uma marca lida como vazia). Marcas duvidosas (rasura, visto, "V", cruz, ponto,
arco, risco, assinatura sobre o quadrado, X quase apagado) viram `REVISAR` em vez de um palpite.
Isso vale para esta folha sintética; não é uma medida de desempenho em fotos reais.

## English

### What it is
The robot reads a photo of an attendance sheet and labels the "P" column square of each row as
`P` (marked with an X), `SEM_MARCAÇÃO` (no mark) or `REVISAR` (doubt: a human decides).
`SEM_MARCAÇÃO` does not mean absent. Signatures and names never decide attendance. All
processing is local and no image is sent to external services.

### What this repository contains
| Part | Where | Available here? |
|---|---|---|
| Synthetic sheet generator | `gerar_folha_sintetica.py` | **Yes**, self-contained code |
| Fictitious sheets and answer key | `exemplos/` | **Yes** |
| Reader results on those sheets | `resultados/` | **Yes**, results only |
| Mark reader (stages 1a and 1b) | — | **No**: private repository |

The files in `resultados/` were **produced by the original reader, kept in a private repository**,
applied to the sheets in `exemplos/`. They document the reader's behavior but **cannot be reproduced
from this repository**. The sheets and `gabarito.json`, however, can be regenerated by anyone with the script.

### Generating the sheets
```bash
pip install numpy opencv-python
python gerar_folha_sintetica.py --saida exemplos
python gerar_folha_sintetica.py --saida exemplos --condicao escura   # a single condition
```
Conditions: `base`, `escura` (dark), `perspectiva_forte` (strong perspective). The script is
deterministic and reads no files. Output: `folha_sintetica_<condition>.jpg` and `gabarito.json`,
which lists, per row, the drawn mark and the label a careful reader should give.

### 100% fictitious data
Title "LISTA DE PRESENCA - DEMO", course "Curso Ficticio de Demonstracao", participants
`PARTICIPANTE FICTICIO NN`, masked ID `000******00` and random IDs. No real photographs, people,
logos or institutional identity.

### Sample results
In `resultados/relatorio_resultados.md` and `resultados/paineis/`: in all 3 conditions, 18 rows,
P = 5, SEM_MARCAÇÃO = 4, REVISAR = 9, 0 mismatches against the answer key and 0 serious errors
(a `P` with no X, or a real mark read as empty). Doubtful marks (scribble, tick, "V", plus sign,
dot, arc, single stroke, signature over the square, nearly erased X) become `REVISAR` instead of a
guess. This holds for this synthetic sheet; it is not a performance measure on real photos.
